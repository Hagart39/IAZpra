# Дашборд ІАЗ: накопичення та узагальнення інформації

Веб-частина прототипу ІАС **PostgreSQL → FastAPI → Web**. На сторінці показано, скільки інформації накопичено, як її оцінено та скільки вже узагальнено. Усі дані синтетичні.

## Що є на сторінці

| Блок | Що показує |
|---|---|
| KPI | накопичено повідомлень, надійшло за добу, % узагальнених, % достовірних (A–B / 1–2) |
| Зведення | текст, що автоматично формується з агрегатів за період |
| Етапи обробки | надійшло → оброблено → узагальнено |
| Накопичення | стовпчики по добах + лінія наростаючого підсумку (Chart.js) |
| Джерела / категорії | розподіл повідомлень |
| Матриця оцінки | надійність джерела (A–F) × достовірність інформації (1–6) |
| Карта | OpenStreetMap (Leaflet) + знаки **milsymbol** для узагальнених повідомлень; недостовірні напівпрозорі |
| Журнал | останні 200 повідомлень зі статусами |

Оформлення відповідає брендбуку: кольори задано в `:root` у `styles.css`. Можна перемикати період (7 / 30 / 90 діб), дані оновлюються автоматично кожні 30 с. Якщо API недоступний, сторінка генерує демо-дані.

## Очікуваний API

`GET http://localhost:8000/reports` →

```json
{
  "data": [
    {
      "id": 1,
      "received_at": "2026-11-09T14:25:00",
      "source_type": "БпЛА",
      "category": "Артилерія",
      "reliability": "B",
      "credibility": 2,
      "status": "generalized",
      "lat": 48.71,
      "lon": 32.05,
      "summary": "Умовне повідомлення"
    }
  ]
}
```

- `source_type`: Донесення підрозділів, БпЛА, Радіорозвідка, OSINT, Спостереження
- `category`: Особовий склад, Бронетехніка, Артилерія, ППО, Логістика (визначає знак на карті)
- `status`: `new` | `processed` | `generalized`

## Запуск

```bash
# бекенд
uvicorn main:app --reload --port 8000

# фронтенд (у папці exam_2026)
python -m http.server 5500
# відкрити http://localhost:5500
```

## Як змінити

- адреса API — `API_URL` у `app.js`;
- довідники джерел, категорій і SIDC-кодів знаків — на початку `app.js`;
- підбір SIDC: https://spatialillusions.com/unitgenerator/
