# Практична 5.5. Дашборд військового аналітика

Шаблон викладача (`Practice55/start`) з заповненими графічними блоками. Дані (`mock.js`) вигадані: українські ПІБ, звання за системою ЗСУ.

1. **Ключові показники**: KPI-картки (особовий склад, групи, середній вік, офіцери).
2. **Чисельність за групами**: стовпчиковий графік (Chart.js).
3. **Структура за званнями**: кільцева діаграма (Chart.js).
4. **Розміщення груп**: карта Leaflet, розмір маркера відповідає чисельності.

Під блоками є таблиця особового складу з фільтром за групою. Дані беруться з `mock.js`.
Верстка адаптивна: на великих екранах 4 блоки в ряд, на середніх 2, на мобільних 1.

**Запуск:** відкрити `index.html` у браузері (потрібен інтернет для Chart.js, Leaflet і тайлів карти).
